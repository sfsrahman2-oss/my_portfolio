# Personal Portfolio (React + Vite)

## Run locally
```bash
npm install
npm run dev
```

## Make it yours
- `src/data/profile.js` – name, title, intro, education, socials, email
- `src/data/projects.js` – project cards (title, image, tech, links)
- `src/data/skills.js` – skills and levels
- `public/images/` – replace the placeholder profile and project images
- `public/cv.pdf` – replace with your real CV

## Deploy
Push to GitHub, then import the repo in Vercel or Netlify (build command `npm run build`, output directory `dist`).
